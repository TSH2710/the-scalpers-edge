# The Scalper's Edge — Project Overview

## What This Is

An online brand and digital product in the day trading / scalping niche. Built from scratch by a scalper, for scalpers.

**Brand:** The Scalper's Edge
**Tagline:** "Trade smarter. Journal harder."
**Domain:** thescalpersedge.com (planned)
**Product:** The Disciplined Trader Journal — Notion template for scalpers ($49)
