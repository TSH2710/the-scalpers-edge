## What This Does:

- **Email 1 (Immediate):** Sends setup instructions + introduces LAUNCH20
- **Email 2 (3 days):** Engages users, checks if they're using it, pitches full version
- **Email 3 (10 days):** Final nudge, asks for feedback, reminds about LAUNCH20

## After Setup:

1. **Test it:** Download the free Lite yourself to trigger the sequence
2. **Monitor:** Check Gumroad → Emails → Workflows to see open rates
3. **Adjust:** If open rates are low, tweak subject lines

## Troubleshooting:

- **Can't find the Lite product?** Make sure you're selecting the $0 product, not the $49 one
- **{{ first_name }} not working?** Delete it and start with "Hey there" instead
- **Emails not sending?** Make sure the workflow is "Active" not "Draft"

## Success Metrics:

- **Email 1 open rate:** Should be 60%+ (it's immediate)
- **Email 2 open rate:** Should be 40%+ (engaged users)
- **Email 3 open rate:** Should be 30%+ (final nudge)
- **Click-through rate:** 5-10% is good for Gumroad emails
